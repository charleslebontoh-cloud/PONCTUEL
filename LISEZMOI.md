# Ponctuel : mise en ligne en 2 minutes

Le GPS du téléphone ne fonctionne que sur une adresse https. Voici le plus simple :

1. Sur un ordinateur, ouvrez https://app.netlify.com/drop (compte gratuit).
2. Glissez le dossier `ponctuel` (décompressé) dans la page. Vous obtenez une adresse https.
3. Sur le téléphone, ouvrez cette adresse dans Chrome, puis menu ⋮ → « Ajouter à l'écran d'accueil ».
4. Dans Ponctuel → Réglages, collez votre clé TomTom gratuite (https://developer.tomtom.com) pour le trafic en direct.
